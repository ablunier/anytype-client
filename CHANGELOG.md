# Changelog

## 0.3.0

- `members.list`.
- Documents that a property with no value may also come as `null`, `""` or `[]`, how a deleted
  select option and linked objects are served, and how to read linked objects' names.

## 0.2.0

- `templates.list` and `properties.list`.
- `AnytypeObjectDocument` types `blocks` and `template_for`.
- Documents how to search a property an object carries without its type listing it.

## 0.1.0

First release, covering what [Calendar for Anytype](https://github.com/ablunier/anytype-calendar)
needs of the local API v2: pairing, `whoami`, spaces, types, select options, search, queries
and their views, reading, creating and editing objects, and file content.
